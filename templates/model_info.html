Files used

  • 1_destinations.csv: 78 destinations, 64 districts, attractions, activities, season, estimated daily budget, accessibility and coordinates.
  • 2_hotels.csv: 487 accommodation records, including rows marked synthetic and BPC official listings.
  • 2b_real_bpc_hotels.csv: official Bangladesh Parjatan Corporation listing records. These are included in the same hotel table used by the live recommender and surfaced in results for their supplied destination IDs; prices and amenities may be missing.
  • BanTABSA.csv: 1,242 Bengali hotel reviews across 31 anonymized hotel IDs and 9 locations. Ratings and aspect sentiment are aggregated by location and used as a small destination-ranking signal where a location matches.
  • 3_users_reviews.csv: 10,000 review/trip records, user budgets, travel style, facilities, trip cost and ratings.
  • 4_transport.csv: 6,354 route/mode/season records with fare, time and distance.
  • tourismdatasetbd_bn.json: 13,813 geolocated tourism records used as supplemental itinerary candidates.
  • itinerary_attractions.csv: generated table combining destination highlight lists and nearby geodata; 1,573 rows across 78 destinations in the current build. Some geospatial associations are approximate.
  • merged_dataset.csv and bangladesh_tourism_dataset.xlsx: supplied merged data and workbook retained in the project for audit/reference; core app logic uses the separate normalized files to avoid depending on duplicated joined rows.

Recommendation design

  • Destination ranking (hybrid): Score = w1·CBF + w2·CF + w3·Popularity + w4·Budget, multiplied by a soft trip-length fit. CBF = TF-IDF interest match + destination-type match + season fit. CF = what similar travellers (same style, similar budget and group size, plus the user's own past trips when known) chose. Popularity = visitor ratings of attractions (shrunk toward the mean), review volume and the BanTABSA city score. Budget = full score while the estimated trip cost is within budget, falling to zero at 25% over. Weights now in use: CBF {{ (hybrid_eff.cbf*100)|round|int }}%, CF {{ (hybrid_eff.cf*100)|round|int }}%, Popularity {{ (hybrid_eff.popularity*100)|round|int }}%, Budget {{ (hybrid_eff.budget*100)|round|int }}%. {% if hybrid_meta.get('tuned') %}They were tuned on validation data ({{ hybrid_meta.get('n_validation_cases') }} held-out trips + {{ hybrid_meta.get('n_scenarios') }} scenarios, `python -m ml.tune_hybrid`); the CF weight is additionally limited while its data is synthetic.{% else %}These are starting values; run python -m ml.tune_hybrid to tune them.{% endif %} CF data: {{ cf_info.get('source','none') }}{% if not cf_info.get('real') %} — synthetic, so the CF signal is a pipeline demo, not evidence about real travellers{% endif %}.
  • Hotel ranking: nightly-price budget fit + available rating + facility overlap + review-count signal.
  • Transport: filters by destination, origin when available, and selected travel season; sorted by fare and time.
  • Day-wise itinerary: ranks candidate attractions by destination-highlight priority, style/interests, available tourism ratings and proximity, then assigns them to daily time slots. Visit durations and costs are heuristic estimates; local traffic and opening hours are not checked.

Research limitations

  • Most review rows are labelled Synthetic placeholder; do not describe them as real customer reviews or use them as evidence of real public sentiment.
  • Many hotel rows are synthetic placeholders. Official BPC listings are now included in hotel results, but some have missing room prices and facilities, which are displayed as unavailable rather than invented.
  • BanTABSA hotel IDs are anonymized. Its city-level ratings must not be presented as ratings of individual named BPC hotels.
  • TF-IDF is an unsupervised content representation, not a supervised classifier. The hybrid score is a transparent weighted formula; only its weights are fitted (on validation data), not an end-to-end prediction model. Hotel ranking uses the same four-signal form with fixed, untuned weights.
  • Budget totals use estimated destination daily budget × days × group size. This is an estimate, not a guaranteed quote. Hotel prices are separate nightly rates where present.
  • No booking transactions, live room availability, live transport availability, or verified current fares are provided.
